# 🎮 DirecdtX11(리그오브레전드 모작)

> DirectX 11과 C++을 기반으로 상용 엔진의 핵심 동작 원리와 렌더링 파이프라인을 직접 구축한 개인 프로젝트입니다.  
> 단순히 기능을 구현하는 것을 넘어, **데이터 직렬화, 멀티 렌더 타겟(MRT) 기반 후처리 조명, 최적화된 네비게이션 시스템**을 설계하는 데 집중했습니다.

## 🚀 핵심 구현 기능 및 트러블 슈팅

### 1. Assimp 모델 및 애니메이션 파이프라인 최적화
* **바이너리 직렬화:** 매번 원본 에셋을 파싱할 때 발생하는 병목을 해결하기 위해, Assimp 데이터를 전용 바이너리로 사전 직렬화(Serialization)하여 로딩 속도와 메모리 효율 극대화
* **GPU 스키닝 & 애니메이션 블렌딩:** 
  * 키프레임 간 실시간 보간 및 계층 구조 연산(`Invalidate_CombinedTransformationmatrix`) 구현
  * 서로 다른 애니메이션 전환 시 포즈를 부드럽게 연결하여 모델 뒤틀림 및 끊김 현상 해결

### 2. 네비게이션 경로 탐색 시스템 (A* + Funnel Algorithm)
* **공간 분할 최적화:** 전체 셀 전수 조사가 아닌 격자 기반 공간 분할을 적용하여 실시간 경로 탐색 연산 비용 최소화
* **경로 최적화:** `A*` 알고리즘으로 최단 경로를 산출한 뒤, `Funnel` 알고리즘의 포탈 판정 로직을 결합해 지그재그 경로를 매끄러운 직선 최단 경로로 보정

### 3. MRT 기반 G-Buffer 및 후처리 조명 연산
* **지오메트리 정보 분할:** Multi-Render Target을 활용해 Diffuse, Normal, Depth, Shade, Specular 정보를 개별 렌더 타겟에 분할 저장
* **다중 광원 최적화:** 포워드 랜더링의 광원 개수 증가에 따른 부하 문제를 해결하기 위해, 후처리 셰이더 기반 조명 연산을 분리하여 화면 해상도에 비례하는 고정 비용으로 다중 광원 처리

### 4. ImGui 기반 통합 에디터 툴 제작
* 지형(`Terrain`), 모델(`Model`), 네비게이션 셀(`Navigation`), 파티클/이펙트(`Effect`), 애니메이션(`Animation`)을 직접 배치하고 실시간으로 디버깅 및 수정할 수 있는 커스텀 툴 구축
